# Unity Project: UnityJunior_SplitCubeOnClick

## Описание
Учебный проект на Unity.
## Взрывы кубов
На сцене находится несколько кубов. При нажатии на куб он исчезает и появляются новые кубы, в случайном количестве от 2 до 6 штук.
У каждого нового куба Scale уменьшен в два раза по всем осям относительно того куба, на который нажал пользователь.
Цвет каждого куба определяется случайным образом.
На каждый куб действует сила гравитации.
Шанс разделения с каждым разом уменьшается в 2 раза начиная со 100%. При успехе идет разделение, иначе куб просто исчезает.
Добавить взрывную силу из центра исчезнувшего куба, которая разбросает только созданные им объекты.
Сделать невидимые ограждения, чтобы кубики далеко не разлетались

## Используемые технологии

## PointerInput
-  Отвечает только за получение пользовательского ввода.
- Отслеживает нажатие кнопки.
- Генерирует событие Pressed.
- Не знает ничего о кубах, сцене или логике.
Назначение: источник сигнала.

## CubeRaycaster
-  Отвечает только за поиск куба в точке клика.
- Получает координату экрана.
- Выполняет Raycast.
- Если найден объект с компонентом Cube, генерирует событие CubeHit(Cube).
- Назначение: преобразует сигнал ввода в конкретную цель.

## Cube
-  Хранит состояние конкретного куба.
- Содержит SplitChance.
- Не содержит логики деления.
- Не знает про спавнер, взрыв или ввод.
- Назначение: данные куба.

## CubeSpawner
-  Отвечает только за создание и удаление кубов.
- Создаёт дочерние кубы.
- Уменьшает масштаб в 2 раза.
- Назначает случайный цвет.
- Настраивает Rigidbody (гравитация и масса).
- Устанавливает шанс деления детям.
- Удаляет родительский куб.
- Назначение: фабрика объектов.

## ExplosionApplier
- Отвечает только за применение физического взрыва.
- Получает центр взрыва.
- Получает список Rigidbody.
- Применяет AddExplosionForce.
- Сила и радиус увеличиваются при уменьшении размера куба.
- Назначение: физический эффект.

## CubeSplitCoordinator
-  Центральная логика сценария.
- Подписывается на события ввода и попадания луча.
- Проверяет шанс деления.
- Определяет количество детей (2–6).
- Вызывает CubeSpawner.
- Вызывает ExplosionApplier
- Удаляет родителя.
- Назначение: координация сценария “деление или исчезновение”.

## Как запустить
1. Открыть проект в Unity Hub
2. Загрузить сцену Main
3. Нажать Play
