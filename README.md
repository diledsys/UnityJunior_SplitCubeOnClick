# Unity Project: UnityJunior_SplitCubeOnClick

## Описание
Учебный проект на Unity.
- ## Взрывы кубов
- На сцене находится несколько кубов. При нажатии на куб он исчезает и появляются новые кубы, в случайном количестве от 2 до 6 штук.
- У каждого нового куба Scale уменьшен в два раза по всем осям относительно того куба, на который нажал пользователь.
- Цвет каждого куба определяется случайным образом.
- На каждый куб действует сила гравитации.
- Шанс разделения с каждым разом уменьшается в 2 раза начиная со 100%. При успехе идет разделение, иначе куб просто исчезает.
- Добавить взрывную силу из центра исчезнувшего куба, которая разбросает только созданные им объекты.
- Сделать невидимые ограждения, чтобы кубики далеко не разлетались
-

- ## Отвечает только за ввод пользователя.
-   Определяет момент активации (клик / тап).
-   Не привязан к конкретному устройству или кнопке.
-   Генерирует событие Activated.
-   Не знает о камере, лучах, кубах и логике игры.
  
- ## ClickRaycaster
-   Отвечает за определение какой объект находится под указателем.
-   Строит луч из камеры через позицию указателя.
-   Выполняет физический Raycast по разрешённым слоям.
-   При попадании в куб генерирует событие CubeClicked(CubeView).
-   Не принимает игровых решений, не знает про спавн и взрывы.
  
- ## CubeView
-   Представляет данные и физическое состояние куба.
-   Хранит номер поколения.
-   Предоставляет доступ к Rigidbody и Renderer.
-   Не содержит логики взаимодействия.
-   Куб является “тупой” сущностью и не управляет своим поведением.
  
- ## CubeSpawner
-   Отвечает за создание и удаление кубов.
-   Создаёт новые кубы при успешном делении.
-   Настраивает трансформ, массу, слой и цвет.
-   Удаляет кубы со сцены.
-   Единственный компонент, управляющий жизненным циклом кубов.
  
- ## ExplosionService
-   Реализует физические эффекты взрыва.
-   Взрыв при неудачном делении толкает окружающие кубы.
-   Радиус и сила взрыва возрастают для более маленьких кубов.
-   Взрыв для новых кубов используется для их разбрасывания.
-   е знает о вводе и вероятностях, работает только с физикой.
  
- ## CubeInteractionController
-   Центральный оркестратор логики игры.
-   Обрабатывает события ввода и клика.
-   Вычисляет шанс деления на основе поколения куба.
-   Решает, создавать ли новые кубы или выполнять взрыв.
-   Координирует работу CubeSpawner и ExplosionService.
-   Единственный компонент, принимающий игровые решения.
  
- ## Probability Rule
-   Шанс деления вычисляется строго по условию задачи:
-   chance = 1 / (2 ^ generation)
-   Поколение 0 → 100%
-   Поколение 1 → 50%
-   Поколение 2 → 25%
-   Вероятность не зависит от порядка кликов.
  
- ## Architectural Principles
-   Разделение ввода, логики и эффектов
-   Отсутствие магических чисел
-   Слабая связность компонентов
-   Цнтрализованное управление жизненным циклом объектовда
